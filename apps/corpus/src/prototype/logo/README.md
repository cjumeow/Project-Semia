# SEMIA Logo — UI prototype (throwaway)

> Five logo directions for SEMIA, switchable via `?variant=A`–`E` on the logo prototype route.

## Run

```bash
npm run prototype:logo
```

Open:

- `http://localhost:5173/?prototype=logo&variant=A` — Pause Point (semicolon)
- `?prototype=logo&variant=B` — Selection (brackets)
- `?prototype=logo&variant=C` — Transcript Arc (wave)
- `?prototype=logo&variant=D` — Layered S (monogram)
- `?prototype=logo&variant=E` — Snippet Tab (index card)

Use **← / →** or the bottom bar to cycle variants.

## Context previews

Each variant shows: hero lockup, sidebar header, extension toolbar, 32px icon, 16px favicon, and dark background.

## After picking a winner

Fold the chosen mark + wordmark into `SemiaSidebar`, extension icons, and `index.html` favicon. Delete or branch the rest.
